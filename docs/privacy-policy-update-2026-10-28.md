## 1. 第 4 节「本地存储、保留与安全」——替换关于凭据的那一句

**中文**，把

> Duty-Agent 对模型凭据和本地服务访问采取适当的保护措施；通过 Windows 客户端保存的
> 模型密钥支持使用操作系统的数据保护机制。本地 API 等受保护功能使用访问控制。……

替换为：

> Duty-Agent 对模型凭据和本地服务访问采取适当的保护措施：**保存的模型 API Key 会先用
> Windows DPAPI（当前用户作用域）加密，再写入本地配置文件，不以明文落盘**；换一台电脑
> 或换一个 Windows 账户后，该密文无法被解开（此时需要重新填写 Key）。本地 API 等受保护
> 功能使用访问控制。您也应保护设备账户、模型密钥与授权令牌，避免向不可信的服务或人员
> 提供访问权限。

**English**：把

> Duty-Agent uses appropriate safeguards for model credentials and local service access.
> Model keys saved through the Windows client support protection using operating-system
> data protection mechanisms. …

替换为：

> Duty-Agent uses appropriate safeguards for model credentials and local service access:
> **saved model API keys are encrypted with Windows DPAPI (current-user scope) before being
> written to the local configuration file, so they are never stored in plain text**. The
> ciphertext cannot be decrypted on another machine or under another Windows account (the
> key must then be entered again). Protected local API features use access controls. …

## 2. 第 4 节末尾——新增 AI 准确性与举报（政策 11.16）

**中文**（接在第 4 节最后一段之后）：

> 本软件的 AI 排班结果由模型生成，**可能不准确、遗漏或不符合您的实际规则**；结果会经过
> 本机校验，并且您可以在排班页面查看和手工修改。如遇到不当的 AI 输出，可通过软件内
> 「设置 → 关于」页面的反馈渠道告知开发者。

**English**：

> AI schedules are generated by a model and **may be inaccurate, incomplete, or
> inconsistent with your rules**. Results pass through local validation, and you can review
> and edit them on the schedule page. To report inappropriate AI output, use the feedback
> channel under Settings → About in the app.

## 3. 第 5 节「您的选择与数据管理」——列表里补两条

**中文**，在现有列表的「在本机查看、修改或删除名单、排班信息及设置；」之后插入：

> - 使用「设置 → 系统 → 数据重置」一次性清空名单、排班与配置（可选同时归档备份）；

并在列表末尾（「备份或清理相关应用数据与日志」之前）插入：

> - **开机自启默认关闭**，仅在您于首次向导或「设置 → 系统」中主动开启后才会写入系统
>   启动项，并可随时关闭；

第 5 节最后再加一句：

> 隐私政策的完整内容可在软件内「设置 → 关于」页面随时打开。

**English**，对应插入：

> - Clear the roster, schedules, and configuration at once via Settings → System → Data
>   reset (with an optional archived backup);
> - **Start with Windows is off by default**; a startup entry is created only after you
>   enable it in the first-run wizard or under Settings → System, and you can turn it off
>   at any time;

以及：

> The full privacy policy is always available in the app under Settings → About.
